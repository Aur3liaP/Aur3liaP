### 💃🏻 About Me
Fullstack JS developer with a soft spot for frontend and product thinking.
I love taking a project from the first User Story all the way to production.

Before code, I spent **11 years in hospitality**: front desk manager, team management, project lead for the EU Ecolabel renewal, and the go-to person for anything IT. That background shapes how I build: user first, pragmatic, and calm when things break.

Coding since **early 2024**, with real production experience on React / NestJS / AWS projects. Curious by nature, always learning something new.

### 🚀 What I've been working on
- 🎲 **Nimble**: real-time synced character sheet extension for Owlbear Rodeo, published on the official store. Built with an **AI-augmented workflow**: specs split into batches, implementation delegated to Claude Code with injected context, systematic review of every output, Vitest tests validated by mutation testing.
- 🤝 **Altivent** (Alt Immersion): open-source app connecting event organizers and volunteers. React, NestJS, MongoDB microservice with NATS, Stripe payments, Jest & Cypress tests, GitLab CI/CD, Docker, AWS.
- 💼 **Freelance**: backend & frontend reinforcement on a SaaS launch (Next.js, NestJS, Prisma, PostgreSQL, Stripe), and a Next.js showcase site scoring **98 performance / 100 SEO** on Lighthouse.
